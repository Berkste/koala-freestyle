# Koala mascot asset

The koala illustration lives here as:

    koala_rapper.png

1024x1024 PNG with a transparent background.

Requirements:
- Real PNG (or JPEG) artwork — never code-drawn (no CustomPainter/Canvas/SVG-recreation/emoji).
- Transparent background preferred.
- Stylized cartoon / modern mascot / hip-hop character aesthetic: headphones,
  a mic, hoodie/streetwear, a confident rap pose. Not kawaii, not a corporate
  mascot, not a realistic photo.

If this file is missing, `KoalaImage` (lib/shared/widgets/koala_image.dart)
renders nothing, so the mascot area is simply hidden. Replacing the PNG at
this path and hot-restarting is the only step needed — no code changes.
